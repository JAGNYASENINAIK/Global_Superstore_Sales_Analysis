Global Superstore Sales & Profit Analysis

About the Project

I created this project in Excel to practice working with a real-world sales dataset and build an interactive dashboard.

The dataset contains sales transactions from 2011 to 2014. I used Excel to clean and organize the data, perform analysis using PivotTables, and create charts and slicers to make the results easier to understand.

What I Worked On

- Cleaned and prepared the dataset
- Converted the data into an Excel Table
- Checked for missing values and duplicate records
- Created calculated columns such as Order Year, Order Month, and Year-Month
- Calculated Profit Margin
- Created PivotTables for different business metrics
- Built an interactive Excel dashboard
- Added slicers to filter the dashboard

Dashboard

The dashboard includes:

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Monthly Sales Trend
- Sales by Category
- Profit by Category
- Sales by Region
- Profit by Region
- Top 10 Products by Sales

Interactive Filters

The dashboard can be filtered using:

- Order Year
- Region
- Category
- Segment

This makes it possible to explore the sales data from different perspectives.

Dataset

The dataset contains 51,290 sales records from 2011 to 2014.

Some of the main fields include:

- Order Date
- Customer
- Segment
- Country
- Region
- Category
- Product
- Sales
- Quantity
- Discount
- Profit
- Shipping Cost

Some Findings

While working on the dashboard, I found that:

- Sales increased over the four-year period.
- Technology had the highest sales among the main categories.
- Technology also had the highest profit among the categories.
- Sales and profit varied considerably across regions.
- A small number of products accounted for a large portion of sales.

How to Use

1. Download the Excel workbook.

3. Go to the Dashboard sheet.
4. Use the slicers to filter the data.
5. Explore the charts and KPIs.
